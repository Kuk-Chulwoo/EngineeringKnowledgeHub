# Roadmap

- v0.1.x: components, documents/revisions, PDF viewing/download, search, persistence,
  tests and Windows setup. Phase 1 stops for engineering review before a release tag.
- v0.2.x: AI datasheet analysis, extraction, source tracking and revision comparison.
- v0.3.x: PADS Logic/Layout VX2.11 library generation and validation.
- v0.4.x: hardware and software/firmware engineering assistance.
- v1.0: production-ready internal platform after operational/security review.

Phase 1 acceptance: start both services; register/search a component; upload and
view/download original PDFs; add revisions without overwriting; restart and retain
metadata; pass backend tests; keep runtime/secrets ignored; push meaningful tested
commits to the specified origin/main; verify local and remote synchronization.
